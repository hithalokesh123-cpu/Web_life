}

#characterstics of javascript
1) client-side-scripting language:
where some of the code can be run on the brower itself no need the server

2)weakly-typed language
where we can perform the operation on different data types like string+number,number+string

3)dynamically-typed language
it decalared the datatype during the run-time based on the value

4)interpreted language
where code execute line by line ,where the debugging is easier

5)sychronous in nature
where the task is exceute one at a time one.
